# Task 2 — Phishing Awareness Training

Read `PHISHING_AWARENESS.md`, then complete `QUIZ.md` before checking the answer key.

The module covers phishing indicators, fake websites, social-engineering tactics, verification practices, reporting, a realistic safe scenario, and an 8-question quiz.

Examples are intentionally non-operational: no credential collection, malware, impersonation infrastructure, or deceptive campaign instructions.
