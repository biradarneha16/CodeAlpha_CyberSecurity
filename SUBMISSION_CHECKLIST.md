# Cybersecurity Tasks — Submission Checklist

- [ ] Task 1 — Network Sniffer: run in an authorized lab and document a sample capture.
- [ ] Task 2 — Phishing Awareness: review the awareness module and quiz.
- [ ] Task 3 — Secure Coding Review: run tests and document remediation.
- [ ] Task 4 — Password Strength Analyzer: run the CLI; do not store real passwords.
- [ ] Task 5 — Mini Vulnerability Scanner: scan only an authorized host and include the generated JSON report.
- [ ] Task 6 — Phishing Email Detection: add a properly sourced labelled CSV locally, train the model, and record metrics. Do not commit private email data.
- [ ] Task 7 — Secure Login System: test registration, login, invalid credentials, and logout locally.
- [ ] Review each README, dependencies, screenshots/evidence, and limitations before submission.

All network/security testing must be restricted to systems you own or are explicitly authorized to assess. Do not claim test results that have not actually been produced.
